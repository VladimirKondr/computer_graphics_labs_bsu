## Задание

## Цветовые модели

### RGB (Red, Green, Blue)
- **Диапазон**: R, G, B ∈ [0, 255]
- **Применение**: Аддитивная модель для мониторов и дисплеев
- **Формула**: Цвет = (R, G, B)

### CMYK (Cyan, Magenta, Yellow, Key)
- **Диапазон**: C, M, Y, K ∈ [0, 100]%
- **Применение**: Субтрактивная модель для печати
- **Формула конвертации из RGB**:
  ```
  K = 1 - max(R', G', B')  где R' = R/255
  C = (1 - R' - K) / (1 - K)
  M = (1 - G' - K) / (1 - K)
  Y = (1 - B' - K) / (1 - K)
  ```

### HSV (Hue, Saturation, Value)
- **Диапазон**: H ∈ [0, 360)°, S, V ∈ [0, 100]%
- **Применение**: Интуитивный выбор цвета (тон-насыщенность-яркость)
- **Формула конвертации из RGB**:
  ```
  max = max(R', G', B')
  min = min(R', G', B')
  Δ = max - min
  
  H = 60° × { (G'-B')/Δ mod 6,  если max = R'
              (B'-R')/Δ + 2,    если max = G'
              (R'-G')/Δ + 4,    если max = B' }
  
  S = Δ / max  (если max ≠ 0)
  V = max
  ```

## Реализация

### color_utils.py

Чистые функции конвертации без состояния:

- `rgb_to_cmyk(r, g, b)` → (c, m, y, k)
- `cmyk_to_rgb(c, m, y, k)` → (r, g, b)
- `rgb_to_hsv(r, g, b)` → (h, s, v)
- `hsv_to_rgb(h, s, v)` → (r, g, b)
- `rgb_to_hex(r, g, b)` → "#RRGGBB"

Все значения округляются до целых чисел для корректного отображения.

### color_model.py

**Класс `ColorModel`** — центральная модель данных:

**Поля**:
- `_r, _g, _b` — RGB компоненты
- `_c, _m, _y, _k` — CMYK компоненты
- `_h, _s, _v` — HSV компоненты
- `_hex` — HEX представление
- `_observers` — список наблюдателей

**Методы**:
- `update_from_rgb(r, g, b, source)` — обновление из RGB, пересчет остальных моделей
- `update_from_cmyk(c, m, y, k, source)` — обновление из CMYK
- `update_from_hsv(h, s, v, source)` — обновление из HSV
- `_notify(source)` — оповещение всех наблюдателей кроме источника изменения

### UI компоненты

#### app.py — главное окно

- Создает tkinter приложение с адаптивным интерфейсом
- Динамическое масштабирование шрифтов при изменении размера окна
- PanedWindow для разделения палитры и ползунков

#### color_sliders_frame.py

Универсальный виджет для отображения ползунков цветовой модели:

**Особенности**:
- Создается для любой модели (RGB/CMYK/HSV) через параметры
- Синхронизация `Scale` и `Entry` через `IntVar`
- Флаг `_is_internal_update` предотвращает циклические обновления
- Автоматическое изменение ширины полей ввода при масштабировании

#### palette_frame.py

Интерактивная HSV-палитра с предпросмотром:

**Компоненты**:
- **Canvas с палитрой**: круговая HSV-карта (H — угол, S — радиус, V — слайдер)
- **Курсор**: отображает текущую позицию цвета на палитре
- **Слайдер Value**: вертикальный, управляет яркостью
- **Preview**: квадрат с текущим цветом
- **HEX поле**: ввод/отображение цвета в формате #RRGGBB

**Алгоритм отрисовки палитры**:
```python
for каждый пиксель (x, y):
    distance = расстояние от центра
    if distance <= radius:
        angle = угол от центра (atan2)
        h = angle в градусах [0, 360)
        s = (distance / radius) × 100
        rgb = hsv_to_rgb(h, s, 100)
        рисуем пиксель
```

## Особенности реализации

### Предотвращение циклов обновления

Проблема: изменение модели → обновление виджета → событие виджета → изменение модели → ...

Решение:
```python
def update_from_model(self):
    self._is_internal_update = True  # блокируем обратные вызовы
    # обновляем UI
    self._is_internal_update = False

def _on_change(self):
    if self._is_internal_update:
        return  # игнорируем события во время обновления
    # вызываем model.update_from_*()
```

## Ограничения и замечания

1. **Точность конвертации**: CMYK → RGB → CMYK может дать немного другие значения из-за округления
2. **Цветовой охват**: Не все CMYK цвета представимы в RGB
