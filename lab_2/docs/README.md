## Теоретическая часть

### Гистограмма изображения

**Гистограмма** — распределение интенсивностей пикселей [0, 255].

Для RGB: 3 гистограммы (R, G, B каналы).

### Эквализация гистограммы

**Цель**: равномерное распределение интенсивностей → повышение контраста.

**Алгоритм**:
1. Вычислить гистограмму `H[i]`
2. Вычислить CDF (cumulative distribution function):
   ```
   CDF[i] = Σ(H[j]) для j от 0 до i
   ```
3. Нормализовать CDF:
   ```
   CDF_norm[i] = CDF[i] × 255 / CDF[255]
   ```
4. Новое значение пикселя:
   ```
   pixel_new = CDF_norm[pixel_old]
   ```

**Два подхода для RGB**:
- **RGB эквализация**: применить к каждому каналу R, G, B отдельно
  - Минус: может исказить цвета
- **HSV эквализация**: конвертировать в HSV, эквализировать только V (яркость)
  - Плюс: сохраняет цветовой тон

### Линейное контрастирование

**Формула**:
```
pixel_new = (pixel_old - min) × (255 - 0) / (max - min)
```

где `min`, `max` — минимальная и максимальная интенсивность в изображении.

**Эффект**: растягивает диапазон до [0, 255].

### Сегментация: обнаружение точек

**Маска Лапласа**:
```
[-1 -1 -1]
[-1  8 -1]
[-1 -1 -1]
```

Выделяет изолированные пиксели (точки) с высокой интенсивностью относительно окружения.

### Обнаружение линий

**Маски для разных направлений**:

Горизонтальные:
```
[-1 -1 -1]
[ 2  2  2]
[-1 -1 -1]
```

Вертикальные:
```
[-1  2 -1]
[-1  2 -1]
[-1  2 -1]
```

Диагональ 45°:
```
[-1 -1  2]
[-1  2 -1]
[ 2 -1 -1]
```

Диагональ 135°:
```
[ 2 -1 -1]
[-1  2 -1]
[-1 -1  2]
```

### Обнаружение границ (перепадов яркости)

#### Оператор Собеля

Вычисляет градиент интенсивности:

```
Gx = [-1  0  1]      Gy = [-1 -2 -1]
     [-2  0  2]           [ 0  0  0]
     [-1  0  1]           [ 1  2  1]
```

Магнитуда градиента:
```
G = √(Gx² + Gy²)
```

#### Оператор Прюитта

```
Gx = [-1  0  1]      Gy = [-1 -1 -1]
     [-1  0  1]           [ 0  0  0]
     [-1  0  1]           [ 1  1  1]
```

#### Оператор Робертса

```
Gx = [ 1  0]         Gy = [ 0  1]
     [ 0 -1]              [-1  0]
```

Более чувствителен к шуму, но быстрее вычисляется.

## Реализация

### histogram.py

**Класс `HistogramProcessor`** — статические методы для работы с гистограммами.

**Методы**:
- `compute_histogram(image)` → histogram(s)
  - Для grayscale: 1 гистограмма
  - Для RGB: 3 гистограммы (R, G, B)
  
- `equalize_histogram_rgb(image)` → Image
  - Эквализация каждого канала RGB отдельно
  
- `equalize_histogram_hsv(image)` → Image
  - Конвертация RGB → HSV
  - Эквализация только V-канала
  - Конвертация HSV → RGB
  
- `linear_contrast_stretch(image)` → Image
  - Линейное растяжение контраста [min, max] → [0, 255]

**Алгоритм `_equalize_channel`**:
```python
hist = histogram(channel)
cdf = cumsum(hist)
cdf_normalized = cdf × 255 / cdf[-1]
equalized = interpolate(channel, cdf_normalized)
```

### segmentation.py

**Класс `SegmentationProcessor`** — методы сегментации.

**Методы**:
- `point_detection(image, threshold)` → Image
  - Свертка с маской Лапласа
  - Пороговая фильтрация
  
- `line_detection(image, direction, threshold)` → Image
  - Направления: `horizontal`, `vertical`, `diagonal_45`, `diagonal_135`
  - Свертка с соответствующей маской
  
- `edge_detection(image, method, threshold)` → Image
  - Методы: `sobel`, `prewitt`, `roberts`
  - Вычисление Gx, Gy, магнитуды
  
- `combined_edge_detection(image, threshold)` → Image
  - Комбинация всех направлений линий
  - Максимум откликов

**Свертка** выполняется через `scipy.ndimage.convolve`.

### image_processor.py

**Класс `ImageProcessor`** — единый интерфейс для всех операций.

Инкапсулирует `HistogramProcessor` и `SegmentationProcessor`, предоставляет методы:
- `process_histogram_equalize_rgb(image)`
- `process_histogram_equalize_hsv(image)`
- `process_linear_contrast(image)`
- `process_point_detection(image, threshold)`
- `process_line_detection(image, direction, threshold)`
- `process_edge_detection(image, method, threshold)`
- `process_combined_edges(image, threshold)`
- `get_histogram(image)`

### ui/app.py

**Класс `ImageProcessorApp(tk.Tk)` ** — GUI приложение.

**Компоненты**:
- Toolbar: загрузка/сохранение изображений
- Левая панель: Canvas для исходного и обработанного изображений
- Правая панель: выбор метода и параметров

**Методы обработки**:
1. **Гистограммы**: 
   - Эквализация RGB
   - Эквализация HSV (V)
   - Линейное контрастирование
2. **Сегментация**:
   - Обнаружение точек
   - Линии: H, V, D45°, D135°
3. **Границы**:
   - Sobel, Prewitt, Roberts
   - Комбинированное

**Параметры**:
- Порог (0–255) для методов сегментации

**Дополнительно**:
- Кнопка "Показать гистограмму" → окно с matplotlib графиками
- Автоматическое масштабирование изображений под Canvas

## Сравнение методов

### Эквализация RGB vs HSV

**RGB**:
- ✅ Максимальный контраст
- ❌ Может исказить цвета (оттенки меняются)

**HSV (V)**:
- ✅ Сохраняет цветовой тон
- ✅ Естественный вид
- ❌ Меньший прирост контраста

**Вывод**: для цветных фотографий лучше HSV, для документов/монохромных — RGB.

### Линейное контрастирование vs Эквализация

**Линейное**:
- ✅ Простое, быстрое
- ✅ Предсказуемый результат
- ❌ Не перераспределяет интенсивности

**Эквализация**:
- ✅ Равномерное распределение → лучший контраст
- ❌ Может усилить шум
- ❌ Иногда "переконтрастирует"

**Вывод**: для малоконтрастных изображений эквализация эффективнее, для слегка тусклых — линейное контрастирование.

### Операторы границ

**Sobel**: баланс точности и устойчивости к шуму — оптимален для большинства задач.  
**Prewitt**: аналогичен Sobel, немного проще в вычислении.  
**Roberts**: быстрый, но чувствителен к шуму — для чистых изображений.

## Особенности реализации

### Оптимизация

- Использование `numpy` для векторизованных операций
- `scipy.ndimage.convolve` для эффективной свертки
- Кэширование `PhotoImage` для предотвращения garbage collection

### Обработка граничных случаев

- Проверка `max == min` при контрастировании → возврат оригинала
- Клиппинг результатов в [0, 255]
- Конвертация в `uint8` для корректного отображения

### Порог в сегментации

**Принцип**: после свертки берем абсолютное значение и применяем порог:
```python
result = |convolved| > threshold ? 255 : 0
```

Значение порога зависит от яркости изображения и требуемой чувствительности.

## Ограничения

1. **Эквализация может усилить шум** в однородных областях
2. **Цветовые искажения** при RGB эквализации ярких/насыщенных изображений
3. **Производительность**: свертка больших изображений (>4K) может быть медленной
4. **Граничные эффекты**: маски 3×3 не обрабатывают крайние пиксели корректно (используется режим по умолчанию)
