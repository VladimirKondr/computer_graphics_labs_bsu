## Теоретическая часть

### 1. Пошаговый алгоритм

**Принцип**: Разделить отрезок на равные шаги по большей координате.

**Алгоритм**:
```
steps = max(|x1 - x0|, |y1 - y0|)
x_step = (x1 - x0) / steps
y_step = (y1 - y0) / steps

для i от 0 до steps:
    x = round(x0 + i × x_step)
    y = round(y0 + i × y_step)
    установить_пиксель(x, y)
```

**Недостаток**: Операции с плавающей точкой на каждом шаге.

### 2. Алгоритм ЦДА (Digital Differential Analyzer)

**Принцип**: Инкрементное вычисление координат с округлением.

**Алгоритм**:
```
dx = x1 - x0
dy = y1 - y0
steps = max(|dx|, |dy|)

x_inc = dx / steps
y_inc = dy / steps

x = x0, y = y0
для i от 0 до steps:
    установить_пиксель(round(x), round(y))
    x += x_inc
    y += y_inc
```

**Преимущество**: Быстрее пошагового за счёт накопления приращений.

### 3. Алгоритм Брезенхема (линия)

**Принцип**: Целочисленные вычисления, основанные на ошибке отклонения.

**Алгоритм** (для |slope| ≤ 1):
```
dx = |x1 - x0|
dy = |y1 - y0|
error = 0

для x от x0 до x1:
    установить_пиксель(x, y)
    error += dy
    если 2 × error ≥ dx:
        y += 1
        error -= dx
```

**Преимущество**: Только целочисленная арифметика, самый быстрый для линий.

### 4. Алгоритм Брезенхема (окружность)

**Принцип**: Симметрия окружности — вычислять 1/8 часть, отражать на остальные октанты.

**Алгоритм**:
```
x = 0, y = radius
d = 3 - 2 × radius

пока x ≤ y:
    установить_8_точек(xc, yc, x, y)
    если d < 0:
        d += 4 × x + 6
    иначе:
        d += 4 × (x - y) + 10
        y -= 1
    x += 1
```

**Функция установки 8 точек** (октанты):
```
(xc ± x, yc ± y)
(xc ± y, yc ± x)
```

### 5. Алгоритм Ву (дополнительно)

**Принцип**: Антиалиасинг — использование полупрозрачности для сглаживания.

Вычисляется интенсивность пикселя на основе расстояния от идеальной линии:
```
intensity = 1 - frac(y)  для основного пикселя
intensity = frac(y)      для соседнего
```

### 6. Алгоритм Кастла-Питвея (дополнительно)

**Принцип**: Модификация Брезенхема с учётом расстояния до идеальной линии для антиалиасинга.

Вычисляет интенсивность на основе отклонения текущей позиции от математически точной траектории.

- Окружность: центр (0,0), радиус 50

- **Сглаживающие алгоритмы** медленнее из-за вычислений интенсивности
- **Брезенхем для окружности** эффективен благодаря симметрии (1/8 вычислений)

## Реализация

### rasterization.py

**Класс `RasterizationAlgorithms`** содержит статические методы:

- `step_by_step(x0, y0, x1, y1)` → список (x, y)
- `dda(x0, y0, x1, y1)` → список (x, y)
- `bresenham_line(x0, y0, x1, y1)` → список (x, y)
- `bresenham_circle(xc, yc, radius)` → список (x, y)
- `wu_line(x0, y0, x1, y1)` → список (x, y, intensity)
- `castle_pitteway(x0, y0, x1, y1)` → список (x, y, intensity)

**Примечание**: Используется библиотека `scikit-image` для эталонных реализаций ЦДА и Брезенхема.

### perfomance_test.py

Бенчмарки для сравнения производительности:
- Измерение времени выполнения
- Подсчёт количества пикселей
- Усреднение по 1000 итераций

### UI

**Интерфейс приложения**:
- Выбор алгоритма (выпадающий список)
- Настройка начальной и конечной точки для линий
- Настройка центра и радиуса для окружностей
- Визуализация на координатной сетке
- Масштабирование и панорамирование
- Отображение координатных осей и подписей

**Привязка координат**: Целочисленные координаты соответствуют **центрам пикселей** в дискретной сетке.

## Пример вычислений

### Брезенхем (линия): (0,0) → (3,2)

```
dx = 3, dy = 2
error = 0

x=0, y=0: пиксель(0,0), error=0+2=2
          2×2=4 ≥ 3 → y=1, error=2-3=-1
x=1, y=1: пиксель(1,1), error=-1+2=1
          2×1=2 < 3 → y не меняется
x=2, y=1: пиксель(2,1), error=1+2=3
          2×3=6 ≥ 3 → y=2, error=3-3=0
x=3, y=2: пиксель(3,2)

Результат: (0,0), (1,1), (2,1), (3,2)
```
